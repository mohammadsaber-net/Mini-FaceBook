# Mini Facebook Clone 📘

Mini Facebook is a full-stack social media application inspired by Facebook.
The project is structured as a monorepo containing two independent applications:
a backend API and a frontend client.

---

## 📦 Project Structure

mini-facebook/
│─ README.md
│
├─ back-end/ → Backend API
│ └─ README.md
│
└─ front-end/ → Frontend Application
└─ README.md

Each folder represents a separate project with its own dependencies and environment variables.

---

## 🧠 Backend
- Authentication with Clerk
- Database management
- Image uploads
- Background jobs & emails

📁 Location: `/back-end`

---

## 🎨 Frontend
- User authentication
- Social feed UI
- State management
- Responsive design

📁 Location: `/front-end`

---

## 🛠 Shared Technologies
- JavaScript / TypeScript
- MongoDB
- Clerk Authentication
- REST APIs

---

## 🎯 Purpose
This project was built to demonstrate:
- Full-stack application architecture
- Authentication & authorization
- Media handling
- Scalable project structure
